# Contenido institucional

La página `/quienes-somos` reproduce el texto de «¿Quiénes somos?», «MISIÓN» y «VISIÓN» de https://www.hoteleslapaloma.com.uy/index.php#quienes, consultado el 21 de octubre de 2026.

El contenido se conserva literalmente por pedido del centro, incluidas la referencia a «32 años de trayectoria» y las expresiones del texto original. No se actualizan cifras ni se corrige la redacción automáticamente. Los párrafos están en `src/content/es.ts`, preparados para agregar traducciones.

La presentación utiliza la identidad visual de la nueva web, con navegación compartida y distribución adaptable a computadora y celular.
